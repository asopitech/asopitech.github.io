# Comparison with C, Rust, and Zig

C provides baseline low-level control. Nim adds inference, richer types, destructors, generics, concepts, templates, macros, and close C ABI integration.

Rust prioritizes making unsafe states unrepresentable through ownership and borrowing. Nim prioritizes concise high-level code while allowing descent to low-level facilities. Zig emphasizes explicit, controllable low-level behavior; Nim tends to wrap similar capabilities in higher-level expressions.
